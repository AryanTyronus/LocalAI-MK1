config.yaml + app.py
{
  "model.default": "mlx-community/Qwen2.5-7B-Instruct-4bit",
  "model.context_window": 4096,
  "memory.short_term.enabled": true,
  "memory.semantic.enabled": true,
  "modes": ["chat","coding","research","agent"]
}

// Start the app server
$ python3 app.py --preload-model
✓ Model loaded
✓ Server ready  http://localhost:8000
✓ Local-first mode active. Live web tools are optional.
